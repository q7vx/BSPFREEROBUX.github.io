Installing Zyphor on Android and Windows

This guide explains safe ways to obtain the Zyphor Android and Windows applications without relying on reposted APKs, unexpected installers or files sent by strangers.

Full privacy policySupport
Section 01

Start with the official downloads portal

Open Zyphor Downloads and choose the platform you use. The portal is the starting point for currently presented releases and archived builds. A release's availability can change. A preview card is not evidence that a download is online: check that a real download link, version and compatible device are shown before trying to install.

Do not install files copied from unsolicited direct messages or from a download mirror claiming to be “more up to date.” A file extension or logo is easy for an attacker to imitate.

Section 02

Android: install and verify

On Android, check the release name and source carefully before opening an APK. Android may ask whether you want to permit installation from that source. Only grant that permission when you deliberately trust the installer and understand the risks, and turn it back off afterward if you do not need it. Do not disable Google Play Protect in response to a stranger's instructions.

If the app does not open, review the device's Android version, available storage and the information accompanying the build. A web-based Zyphor page remains an alternative when a native release is not compatible with your phone.

Section 03

Notifications and background behavior

The Android experience may request notification permission. If an alert does not appear, inspect both Android's application notification setting and any battery-saving restrictions. Force-stopping an app can delay background delivery. An internet connection and server availability are required for most account actions.

Web browser calls and push notifications are separate features. You should not assume that the browser will maintain a live audio or video call while completely suspended.

Section 04

Windows: review the installer

Choose the Windows family in the official download portal. Confirm that the download address is associated with the authorized Zyphor distribution route and that the file name matches the published release. Scan the file using your normal security tools before running it, especially if the installer is unsigned or Windows displays an unfamiliar publisher warning.

If a release depends on background processes, startup options or notification access, review those options in the application itself. Do not grant administrative rights unless the installer clearly needs them and you trust its source.

Section 05

Updates, previous versions and compatibility

Newer is not automatically better for every device. Check the published release notes and compatibility details for your operating system. If you need a previous build, use an archived official release rather than a random third-party copy. Back up important personal files before replacing or removing software.

The website and native apps can present similar features with different controls. A change to a web page does not prove that every native client has already been updated.

Section 06

When installation fails

Record the platform, build version, error wording and what happened after you opened the installer. For Android, include the Android version and whether the problem happened before or after the app started. For Windows, include the Windows version and whether an antivirus or signature warning was displayed.

Contact Zyphor Support with these details. Do not upload passwords, account tokens, private messages or the contents of a secure account vault to a public issue or support screenshot.
