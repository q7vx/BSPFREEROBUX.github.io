Zyphor help and troubleshooting

These checks focus on symptoms that visitors can actually diagnose. They do not require sharing a password, recovery token, session identifier or private chat transcript with strangers.

Open ZyphorContact support
Section 01

Sign-in and session problems

Open the official sign-in page and make sure that the address bar shows zyphor.cc. Check the username, keyboard layout and whether Caps Lock is enabled. If a screen repeatedly returns to login, the saved session may have expired or been revoked. Sign out and sign in again where possible, rather than copying session information between devices.

If the password is forgotten, use the official recovery flow. A reset link may expire or only work once. Start a fresh request if the link is no longer valid. Use Support if recovery is unavailable; support staff should not ask you to reveal your password.

Section 02

A page remains on a loading screen

Some Zyphor screens first load static files and then contact a service endpoint for live account data. If the interface displays “Connecting,” check whether other websites load on the same connection. Try a normal refresh before deleting local data. If a service endpoint is unavailable, repeatedly clicking account or payment controls will not fix it.

For reproducible issues, write down the page name, approximate time, device and browser version. If a developer console shows errors, you can share the error wording after removing any tokens or personal information.

Section 03

Messages, friends and notifications

First verify you are signed in. If a conversation is empty, select a friend from the list and confirm you are viewing the correct chat. Some chat features can be permission-limited or unsupported on certain browsers. Grant microphone or camera access only when intentionally starting a call.

On a mobile browser, messages or calls can be suspended when the browser is backgrounded. System battery-saving settings and browser behavior vary; do not depend on a web call remaining active after the device suspends the browser. Reopen the app to reconnect if needed.

Section 04

Photo uploads and cloud files

Use PNG, JPG or JPEG images in Zyphor Cloud. Check file size restrictions shown on the upload control, and make sure the connection stays active until the upload finishes. A filename appearing in a chooser does not mean the upload succeeded. For a missing image, try the library search or refresh before uploading another copy.

Keep original files elsewhere. Contact Support if a successful upload does not appear in the library, and provide an approximate time and the file type, not the private file itself unless necessary.

Section 05

Purchases, gifts and transfers

For subscriptions or Zyphium transfers, verify the recipient, amount and offer terms before confirming. A stale UI value is not evidence that a payment was accepted. Check the platform activity history and any official receipt rather than repeating a payment. If it appears incorrect, stop and contact Support with the transaction reference.

Never hand over a session token, account password or verification code in exchange for a promised payout, free virtual currency or rare collectible.

Section 06

Android and desktop installation

Only use official releases advertised at Zyphor Downloads. Android versions can require permission for notifications. If notifications do not appear, inspect both the app's notification permission and the phone's notification settings. Battery optimization may delay background activity.

For Windows, verify the download source and check the release information before installing. Do not bypass operating-system security warnings merely because someone in a chat tells you to do so. The installation guide covers this more closely.

Section 07

How to submit a useful support ticket

A good report states: the exact page or feature, the last action performed, what you expected, the actual result, and the approximate time. If the problem is device-specific, include browser or operating-system version. Screenshots should hide other people's messages and private account data.

Visit Support to open a ticket. For abuse reports, also see the community guidelines. Do not post credentials or tokens in a public issue or feature suggestion.

Need assistance? Zyphor is updated frequently. If a button, feature or release is unavailable, use Support rather than relying on an outdated third-party download or tutorial. See the Privacy Policy and Terms of Service.
